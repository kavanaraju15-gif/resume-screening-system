# Resume Screening System

An AI-powered Resume Screening System that analyzes resumes and matches candidates with job requirements.

🚀 **Live Demo:** [Click here to use the Resume Screening System](https://resume-screening-system-cbsf7cjtsbrkdbisutndb5.streamlit.app/)

## Features

* 📄 Resume upload
* 🤖 Resume screening
* 🎯 Job description matching
* 📊 Candidate matching score
* ⚡ Fast and easy-to-use interface

## Technologies Used

* Python
* Streamlit
* Machine Learning
* Pandas
* Scikit-learn
* PyPDF
